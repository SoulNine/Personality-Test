# Soul Nine: "Which light are you?" personality quiz

This is a free web quiz that leads players to the Soul Nine Steam page. The loop: someone sees a TikTok or stream, takes the quiz, gets a result card, shares or compares with a friend, and lands on Steam.

- **Plain HTML/CSS/JavaScript.** No framework, no build step for the site itself, and no backend.
- **About 96 KB to load** (54 KB compressed), including the font.
- **Works on any static host.** Cloudflare Pages is recommended.

## What's in it

| Path | What it is |
|---|---|
| `index.html`, `css/style.css`, `js/app.js` | The site: intro, 10 questions, reveal, result, a friend's shared result, and the pair screen |
| `site.config.js` | **Your settings:** domain, Steam link, trailer, socials, analytics, "X% share your type" |
| `js/data.js` | **Questions and all type texts.** Edit here. |
| `js/scoring.js` | Scoring, tie-breaks and result codes (`6w5`) |
| `js/pairs.js` | Templates for "compare with a friend" |
| `js/sigils.js`, `js/card.js` | The nine glowing emblems and the share cards (1080×1920 story, 1080×1080 square, 1200×630 link preview), drawn in the browser |
| `js/ambient.js` | Drifting light motes and the optional ambient sound (generated, no audio files) |
| `type/1.html` … `type/9.html` | Share pages, so link previews show the right type. They redirect to the result. Generated by `npm run build`. |
| `og/*.jpg` | Link-preview images. Generated by `npm run build`. |
| `tools/check.mjs` → `tools/sim_results.md` | Balance checks and simulation |
| `tools/screenshots.mjs` → `screenshots/` | Headless browser test plus screenshots and sample cards |

## Run it locally

You need Node.js 18 or newer.

```bash
npm install          # only needed for the build/screenshot tools (puppeteer-core)
npm run serve        # http://localhost:8080
```

Useful test links:
- `http://localhost:8080/?demo=6w5` jumps straight to a result.
- `http://localhost:8080/type/2?w=1` shows a friend's shared result.
- `http://localhost:8080/?compare=9w1` shows the intro with a compare invite.

## Edit questions and texts

- **Texts** (names, taglines, lines, growth teasers, wing phrases): edit `js/data.js` → `TYPES`. Then run `npm run build` so the preview images update.
- **Questions:** edit `js/data.js` → `QUESTIONS`.
  - Each option is `["text", primaryType, secondaryType]`. The primary type gets +2 points and the secondary +1.
  - **You can reword freely.** If you change any numbers, run `npm run check`. It must say PASS for every line, otherwise some types become easier to get than others.
  - The rules: each type is primary in exactly 4 options and secondary in exactly 4; a type appears at most once per question; and a random player's expected score is equal for every type.
- **Options are shuffled on screen** each time, so their order in the file doesn't matter.
- **Compare texts:** `js/pairs.js` (templates) plus `gift`, `verb`, `friction` and `same` per type in `data.js`.

## Change the Steam link or the domain

1. Edit `site.config.js`:
   - `steamUrl`: keep `?utm_source=quiz...` so you can see quiz traffic in Steam's UTM report.
   - `siteUrl` and `cardDomain`.
2. Run `npm run build`. It rewrites the preview tags and images with the new domain; they need the full domain to work on social sites.
3. Commit and push. Cloudflare redeploys automatically.

## Deploy (recommended: Cloudflare Pages, free)

Static files on Cloudflare Pages' free plan have free, unlimited requests and bandwidth, plus 500 deploys a month ([limits](https://developers.cloudflare.com/pages/platform/limits/), [pricing](https://developers.cloudflare.com/pages/functions/pricing/)).

1. Push this folder to a GitHub (or GitLab) repository:
   ```bash
   git remote add origin git@github.com:<you>/soulnine-quiz.git
   git push -u origin main
   ```
2. In the Cloudflare dashboard, go to **Workers & Pages → Create → Pages → Connect to Git** and pick the repo.
3. Build settings:
   - **Framework preset:** None
   - **Build command:** *(leave empty)*
   - **Build output directory:** `/`

   The preview images and share pages are generated on your computer with `npm run build` and committed, so Cloudflare only serves files.
4. Deploy. You get `https://<project>.pages.dev`.
5. **Custom domain:** in the project, go to **Custom domains → Set up a domain**.
   - If the domain is registered with or managed by Cloudflare, it's one click.
   - Otherwise, add the CNAME record Cloudflare shows you at your registrar.
6. Put the final domain into `site.config.js`, run `npm run build`, then commit and push.
7. **Test the link previews** with a share debugger:
   - <https://developers.facebook.com/tools/debug/>
   - <https://cards-dev.twitter.com/validator> (may be retired)
   - or paste a `/type/6?w=5` link into a private chat.

**Buying the domain**
- **Cloudflare Registrar** sells domains at cost, with no markup, and connects to Pages most simply.
- **Namecheap** and **Porkbun** are good alternatives.
- Short `.com` or `.gg`/`.io`-style names work well in TikTok captions. Check renewal prices, not just the first year.

**Alternatives**
- **Netlify:** "Add new site → Import from Git", no build command, publish directory `.`. `_headers` works there too.
- **GitHub Pages:**
  - Turn it on in *Settings → Pages* and deploy from the `main` branch root.
  - Share links like `/type/6` work there.
  - If you use a project URL (`user.github.io/soulnine-quiz/`) rather than your own domain, set `siteUrl` to that full URL.

## Analytics (optional, off by default)

Nothing is tracked unless you turn it on in `site.config.js`:
- **Cloudflare Web Analytics** (free, no cookies): paste the token into `analytics.cloudflareToken`. Alternatively, enable it with one click in the Pages project and leave the token empty.
- **Plausible** (paid, privacy-friendly): put your domain into `analytics.plausibleDomain`.

If you add anything that uses cookies, you'll need a consent banner for EU visitors.

## "X% share your type"

This is off by default and **should only show real numbers**:
- Collect them first, for example by counting result-page views per type in your analytics.
- Then fill in `typeShare.percentByType` and set `enabled: true`.

## Test

```bash
npm run check        # balance + simulation -> tools/sim_results.md
npm run screenshots  # plays the quiz in headless Chrome -> screenshots/, fails on any JS error
npm run build        # share pages + preview images
```

`build` and `screenshots` use your installed Chrome. If it isn't found, set `CHROME_PATH=/path/to/chrome`.
